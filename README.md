# Bead Pocket downloads

Official installation packages for 豆豆口袋 (Bead Pocket).

[Website and downloads](https://beadpocket.com/#platforms) · [Web app](https://beadpocket.com/app/) · [Support](https://beadpocket.com/support.html) · [Privacy](https://beadpocket.com/privacy.html)

[0.1.3 development release](https://github.com/Cy2854/bead-pocket-downloads/releases/tag/v0.1.3):

- Windows 10+ x64 NSIS installer (not Authenticode signed).
- Android 7.0+ ARM64 signed APK, application ID `com.beadpocket`.
- macOS 13+ Apple Silicon and Intel DMGs (ad-hoc signed; not Developer ID signed or notarized).

Each release includes SHA-256 checksums. Web, Windows, Mac and Android allow three successful pattern generations per local day. Images and inventory are stored locally; there is no account or automatic cloud sync.

0.1.3 changes the application identity. Preserve old installations and export desktop backups before migrating; Android data does not move automatically between package names. Read the release notes before installation. iPhone/iPad distribution is separate through Apple's services.

This repository contains installation packages and release notes only. Application source and signing credentials are not published here.
